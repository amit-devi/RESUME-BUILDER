# RESUME-BUILDER
THIS PROJECT CREATING ATS FRIENDLY RESUME FOR EVERY TRADE AND FIELDS IT IS VERY UI TO INTERACT USER OR CREATING A SMART RESUME FOR THE JOB

<p>A clean, responsive, and interactive Resume Builder web application built with vanilla JavaScript, HTML5, and Tailwind CSS. It allows users to create, customize, and preview professional resumes in real time and export them directly to PDF.</p>

# Features

<ul><li>⚡ Instant Real-Time Preview: Watch changes update live on the simulated A4 sheet as you type.</li></ul>

# Multiple Layout Templates:
<ul>
  <li>Modern Executive: Top accent header with clean section dividers.</li>
  <li>Split Sidebar: Two-column dark accent layout for tech and creative profiles.</li>
  <li>Minimal Classic: Elegant serif typography focused on readability and simplicity.</li>
</ul>

<ul>
  <li>Dynamic Color Themes: Instant one-click accent color switching (Blue, Teal, Purple, Rose, Slate).</li>
</ul>

# Dynamic Section Managers:
<ul>
  <li>Add, update, and remove multiple Work Experience records.</li>
  <li>Manage Education and certifications dynamically.</li>
  <li>Add Projects with repository and demo URLs.</li>
  <li>Interactive Skills tag manager with tag deletion and comma/enter-separated insertion.</li>
</ul>

# A4 Print & PDF Ready: 
<p>Configured with dedicated print stylesheets (@media print) that strip all editor UI and cleanly export a single-page or multi-page A4 document without clipping.</p>

# Sample Data Loader & Quick Clear: 
<p>Pre-fill the form with a polished profile demo in one click to test layouts instantly.</p>

# Fully Responsive: 
<p>Works across desktops, laptops, and tablets.</p>

# Built With

<ul>
  <li>HTML5: Semantic document structuring.</li>
  <li>Tailwind CSS: Modern utility-first styling via CDN.</li>
  <li>Vanilla JavaScript (ES6+): Reactive state management and dynamic DOM updates with zero external framework dependencies.</li>
  <li>Font Awesome: UI and contact icons.</li>
  <li>Google Fonts: Inter and Merriweather.</li>
</ul>
